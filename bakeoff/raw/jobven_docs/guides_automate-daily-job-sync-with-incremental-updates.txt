Instead of fetching all jobs every time, use postedAfter to only get jobs posted since your last sync. This reduces API calls and processing time. How It Works The postedAfter parameter filters jobs to those posted after a Unix timestamp (seconds): # Jobs posted in the last 24 hours curl -H " X-API-Key: $JOBVEN_API_KEY " \ " https://api.jobven.com/v1/public/jobs?postedAfter=1735257600 " The Pattern First sync : Fetch all jobs (or start from a recent date) Save timestamp : Record when you started the sync Next sync : Use saved timestamp in postedAfter Repeat : Each sync only fetches new jobs Examples JavaScript import fs from ' fs ' ; const TIMESTAMP_FILE = ' ./last_sync.txt ' ; function getLastSync () { try { return parseInt ( fs . readFileSync ( TIMESTAMP_FILE , ' utf8 ' )) ; } catch { // First run - start from 7 days ago return Math . floor ( Date . now () / 1000 ) - ( 7 * 24 * 60 * 60 ) ; } } async function syncNewJobs () { const lastSync = getLastSync () ; const syncStart = Math . floor ( Date . now () / 1000 ) ; const jobs = [] ; let cursor = null; do { const params = new URLSearchParams ( { postedAfter : lastSync . toString () , limit : ' 100 ' } ) ; if ( cursor ) params . set ( ' cursor ' , cursor ) ; const response = await fetch ( ` https://api.jobven.com/v1/public/jobs? ${ params }` , { headers : { ' X-API-Key ' : process . env .
