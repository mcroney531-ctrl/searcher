The Jobs API returns results in pages. Each response includes a cursor you can use to fetch the next page. Response Structure Every response includes pagination info in the meta object: { " data " : [ ... ], " meta " : { " count " : 100 , " nextCursor " : " eyJpZCI6ImFiYzEyMyJ9 " , " hasMore " : true } } Field Description total Exact number of jobs matching your filters.
